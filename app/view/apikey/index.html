安全说明

· Secret 只在创建/重置时显示一次，服务器使用系统密钥加密保存。

· API 只能看到DNS账户、证书账户、部署账户的类型和备注，看不到账户名称、面板地址和任何密钥，也不能修改这些账户、用户和系统设置。

· 每一次API调用（包括签名错误、无权限、超频被拒绝的请求）都会记入 审计日志。

· SSH、FTP、复制到本机、S3存储类型的部署任务只能在后台创建和修改，API只能执行。

· 同一IP连续认证失败20次将被封禁15分钟。

· 建议按用途分开创建密钥，只给需要的权限、域名和IP。
