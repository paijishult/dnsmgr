开始使用

管理API密钥

以下基础接口与扩展接口全部使用 POST 请求，参数以表单格式（application/x-www-form-urlencoded）提交，返回 JSON。接口地址前缀：

{$siteurl}/api

新接入推荐使用 HMAC v2 请求头签名，支持请求内容校验、防重放与幂等。以下为继续兼容的旧版表单认证，两种身份任选其一：

方式认证参数签名算法权限
API密钥（推荐）

timestamp 为当前 Unix 时间戳（秒），与服务器时间相差不能超过 5 分钟；+ 表示直接拼接字符串，sign 取 32 位小写。

返回格式：成功时 code 为 0；列表接口直接返回 {"total":总数,"rows":[...]}，分页使用 offset（偏移量，默认 0）和 limit（条数，默认 20，最大 1000）。失败时返回 {"code":-1,"msg":"错误原因"}。

HTTP状态码说明
200请求已处理，以返回内容中的 code 判断是否成功
400缺少必填参数或参数格式不正确
403认证失败：参数缺失、时间戳不合法、签名错误、密钥已禁用/过期、IP不在白名单、缺少该接口所需权限
404接口不存在（注意所有接口都是 POST）
409v2 Nonce 重复、幂等键冲突、请求仍在执行，或上次结果不确定；请核对响应说明
429超过密钥的频率限制，或同一IP认证失败次数过多（20次）被临时封禁15分钟
500服务器内部错误（不会返回调用栈等内部信息）

每一次调用（包括认证失败、无权限和超频被拒绝的请求）都会记入后台 审计日志，参数中的密钥类字段会脱敏保存。API 返回的DNS/证书/部署账户只包含ID、类型和备注。

HMAC v2 与幂等请求（推荐）

业务参数仍使用 POST 表单；认证放在请求头：X-Dnsmgr-Version: 2、X-Dnsmgr-Keyid（或 X-Dnsmgr-Uid，二选一）、X-Dnsmgr-Timestamp、X-Dnsmgr-Nonce 和 X-Dnsmgr-Signature。时间误差不超过300秒，Nonce每次重新生成，原始请求体不超过2MB。

以下8项使用单个LF换行连接，计算 HMAC-SHA256 后取64位小写十六进制；使用对应身份的 Secret。URI包含原样查询串，不包含协议和主机名。未使用幂等键时最后一项为空，因此签名串以换行结尾。

DNSMGR-HMAC-SHA256
keyid:你的KeyID（用户API使用uid:用户ID）
POST
/api/domain/data
SHA256(原始请求体)的十六进制
时间戳
Nonce
Idempotency-Key或空字符串

Nonce及幂等键允许16–128个字母、数字、下划线或短横线。签名后必须原样发送请求体，不能重新编码。

import hashlib, hmac, os, time, uuid
from urllib.parse import urlencode
from urllib.request import Request, urlopen

keyid, secret = os.environ["DNSMGR_KEYID"], os.environ["DNSMGR_SECRET"]
uri = "/api/domain/data"
body = urlencode(dict(offset=0, limit=20)).encode("ascii")
ts, nonce = str(int(time.time())), uuid.uuid4().hex
operation_id = ""  # 读接口留空；受支持的写操作重试需复用同一业务ID
canonical = "\n".join(["DNSMGR-HMAC-SHA256", "keyid:" + keyid,
    "POST", uri, hashlib.sha256(body).hexdigest(), ts, nonce, operation_id])
headers = {"Content-Type": "application/x-www-form-urlencoded",
    "X-Dnsmgr-Version": "2", "X-Dnsmgr-Keyid": keyid,
    "X-Dnsmgr-Timestamp": ts, "X-Dnsmgr-Nonce": nonce,
    "X-Dnsmgr-Signature": hmac.new(secret.encode(), canonical.encode(), hashlib.sha256).hexdigest()}
if operation_id:
    headers["Idempotency-Key"] = operation_id
req = Request(os.environ["DNSMGR_URL"].rstrip("/") + uri,
    data=body, headers=headers, method="POST")
with urlopen(req, timeout=60) as response:
    print(response.read().decode())

可选 Idempotency-Key 支持：/api/record/{add|update|delete|status|remark|batch|batchedit|batchadd|apply}/:id、/api/batch/enqueue、/api/batch/task/{cancel|retry}、/api/cert/deploy/process。其他接口携带幂等键返回400。

同一写操作重试复用幂等键、URI及原始请求体，重新生成Nonce和签名。确认过的结果保存7天，重放附带 Idempotency-Replayed: true。相同键更换请求或权限发生变化返回409；上次执行结果不确定也返回409，须核对远端状态，不能换新键盲目重试。重复Nonce始终返回409。

import hashlib, time, requests

BASE = "{$siteurl}/api"
KEYID = "你的KeyID"
SECRET = "你的Secret"

def call(path, **params):
    ts = str(int(time.time()))
    sign = hashlib.md5((KEYID + ts + SECRET).encode()).hexdigest()
    data = {"keyid": KEYID, "timestamp": ts, "sign": sign, **params}
    return requests.post(BASE + path, data=data, timeout=60).json()

# 申请证书 → 推送到服务器
print(call("/cert/order/add", aid=1, **{"domains[]": ["example.com", "*.example.com"]}, keytype="RSA", keysize="2048"))
print(call("/cert/deploy/process", id=1, reset=1))
<?php
function dnsmgr_api($path, array $params = []) {
    $keyid = '你的KeyID';
    $secret = '你的Secret';
    $ts = time();
    $params += ['keyid' => $keyid, 'timestamp' => $ts, 'sign' => md5($keyid . $ts . $secret)];
    $ch = curl_init('{$siteurl}/api' . $path);
    curl_setopt_array($ch, [CURLOPT_POST => true, CURLOPT_POSTFIELDS => http_build_query($params), CURLOPT_RETURNTRANSFER => true, CURLOPT_TIMEOUT => 60]);
    $res = curl_exec($ch);
    curl_close($ch);
    return json_decode($res, true);
}

print_r(dnsmgr_api('/record/data/1', ['offset' => 0, 'limit' => 20]));
const crypto = require('crypto');

const BASE = '{$siteurl}/api';
const KEYID = '你的KeyID';
const SECRET = '你的Secret';

async function call(path, params = {}) {
  const ts = Math.floor(Date.now() / 1000).toString();
  const sign = crypto.createHash('md5').update(KEYID + ts + SECRET).digest('hex');
  const body = new URLSearchParams({ keyid: KEYID, timestamp: ts, sign, ...params });
  const res = await fetch(BASE + path, { method: 'POST', body });
  return res.json();
}

变更预览与后台任务

沿用上方 API 签名方式。下列路径均在 /api 前缀之后，:id 是系统中的域名 ID。预览只展示差异，执行前再次检查域名权限和当前记录是否变化。

POST 路径权限参数及返回
/record/history/data/:idrecord:readoffset、limit 获取快照列表；传 snapshotid 获取该快照的记录数组 data。
/record/snapshot/:idrecord:write可选 label，返回 snapshot_id；每个域名最多保留最近 100 份。
/record/preview/:idrecord:readoperations 为 JSON 数组，最多 500 项、1 MB；返回 data.token、data.expires、data.changes。
/record/rollback/preview/:idrecord:write传 snapshotid，返回回滚差异及预览令牌；根域名 NS、SOA 保持原样。
/record/apply/:idrecord:write传 token，立即执行已预览的差异。查看 data.results 中每项的 index、success、message；部分失败时 code=-1，应核对现状并重新预览。
/batch/enqueuerecord:writedid、token，可选 name；返回任务 id。由现有计划任务在后台执行。
/batch/datarecord:readoffset、limit；返回任务列表 total、rows，每页最多 100 条。
/batch/detailsrecord:read传任务 id；返回任务摘要 task 及逐项 results。index 从 0 开始。
/batch/task/retry
/batch/task/cancel		record:write传任务 id。失败且未过期的任务可重试；取消在当前云端请求结束后的检查点生效。

operations 支持 add、update、delete、status、remark。修改已有记录时需传该域名真实的 recordid；添加或修改传 name、type、value，可选 line、ttl、mx、weight、remark。

[{"action":"add","name":"www","type":"A","value":"192.0.2.1","line":"default","ttl":600}]

预览令牌有效期 10 分钟，绑定当前身份和域名，执行或入队后一次性消耗。后台任务有效期 24 小时，执行期间持续复核权限；凭据或解析现状变化时应重新预览。任务状态：0 排队、1 执行中、2 完成、3 失败、4 取消。
